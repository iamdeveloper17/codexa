# Codexa

AI-powered design-to-code generator with GSAP animations.

## ✨ Features

- 🎨 GSAP hero animations (SplitText, Timeline)
- 🤖 AI code generation with streaming
- 💻 Live code preview with syntax highlighting
- 📋 One-click copy to clipboard
- 🎯 Responsive design
- ⚡ Next.js 16 + Turbopack

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP
- **AI:** OpenRouter API (Llama 3.3 70B)
